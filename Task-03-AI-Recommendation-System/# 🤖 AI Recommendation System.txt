# 🤖 AI Recommendation System

## 📌 Project Overview

This project is a simple AI-based Recommendation System developed using **Python**, **TF-IDF Vectorization**, and **Cosine Similarity**.

The system recommends the most relevant courses based on the user's interests. It compares the user's input with the course dataset and ranks the recommendations according to similarity scores.

This project was developed as **Project 3** of the **DecodeLabs Artificial Intelligence Industrial Training Program**.

---

## 🎯 Objectives

- Build a simple AI Recommendation System.
- Learn Content-Based Filtering.
- Understand TF-IDF Vectorization.
- Apply Cosine Similarity for recommendations.
- Rank courses based on similarity scores.

---

## 🚀 Features

- User enters their interests.
- Uses TF-IDF to convert text into numerical vectors.
- Uses Cosine Similarity to compare user interests with available courses.
- Displays the Top 3 recommended courses.
- Shows similarity score and match percentage.
- Displays the best recommendation.
- Allows the user to get recommendations multiple times.

## ▶️ How to Run

1. Open Google Colab or Jupyter Notebook.
2. Copy and paste the project code.
3. Run all cells.
4. Enter your interests.

Example:

```
python ai machine learning
```

The system will display:

- Top AI Recommendations
- Similarity Score
- Match Percentage
- Best Recommendation
