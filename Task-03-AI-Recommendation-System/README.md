# 🤖 Task 03 — AI Recommendation System

A content-based AI Recommendation System developed using Python, TF-IDF Vectorization, and Cosine Similarity.

The system recommends relevant courses based on user interests and ranks them according to similarity scores.

## Technologies Used

- Python
- Google Colab
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## AI Concepts Used

- Content-Based Filtering
- TF-IDF
- Cosine Similarity
- Text Vectorization
- Basic Natural Language Processing
