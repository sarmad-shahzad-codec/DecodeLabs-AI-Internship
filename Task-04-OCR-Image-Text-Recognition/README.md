# 🔍 Task 04 — OCR Image Text Recognition

An AI-based Image Text Recognition System developed using Python, OpenCV, and Tesseract OCR.

The system extracts text from uploaded images after image preprocessing and provides useful statistics such as word count, character count, line count, OCR confidence score, and processing time.

## Technologies Used

- Python
- Google Colab
- OpenCV
- Tesseract OCR
- Matplotlib
- Pillow

## Key Features

- Single and multiple image upload
- Image preprocessing
- Grayscale conversion
- Gaussian Blur
- Thresholding
- OCR text extraction
- OCR confidence score
- Word, character, and line count
- Processing time calculation
- Save extracted text to TXT file
