# 🤖 AI-Based Image Text Recognition System Using OCR

## 📖 Project Description

This project is developed as part of the Artificial Intelligence course. The main purpose of this project is to extract text from images using Optical Character Recognition (OCR). The system allows users to upload one or multiple images, processes them using OpenCV, and extracts text with the help of the Tesseract OCR engine.

The project also provides useful statistics such as word count, character count, line count, confidence score, and processing time. Finally, all extracted text is saved into a text file for future use.

---

## 🎯 Project Objectives

- Extract text from images using OCR.
- Preprocess images to improve text recognition.
- Display extracted text in a readable format.
- Calculate useful text statistics.
- Save extracted text into a text file.
- Support multiple image uploads.

---

---

## 📂 Project Features

- Upload single or multiple images.
- Display the original image.
- Convert image into grayscale.
- Remove image noise using Gaussian Blur.
- Apply thresholding for better OCR accuracy.
- Extract text from images.
- Display extracted text.
- Count words, characters, and lines.
- Calculate OCR confidence score.
- Measure processing time.
- Save extracted text into a TXT file.
- Automatically download the result file.
